# GTA VI PC Port Race — live tracker

Unofficial fan dashboard tracking community efforts to run GTA VI natively on PC
(Leonida Reloaded, XCL, VIctory). Progress percentages are estimates; pull requests and
commits come from each project's public repository.

Contains no game code, game files or assets. Not affiliated with Rockstar Games or Take-Two Interactive.

Pages: `index.html` (dashboard) · `stream.html` (race scene) · `leonida.html` (Leonida Reloaded)
